# OpsPilot v1.0.1 Release Record

- Status: Complete
- Date: 2026-08-13
- Release type: Local portfolio hardening release
- Scope rule: v1.1 remains reserved for the real media-processing pipeline

## Product Improvements

- Full event lifecycle from Draft through Archived, including a reversible Ready-to-Configuring path.
- Archived events are read-only in both the product surface and every evidence mutation route.
- Event ownership, schedule, timezone, audience size and description can be edited in Launch Control.
- Watch-page content can be created, edited, hidden or removed with confirmation.
- Ready media can be attached once, visibly identified as attached, and detached with readiness recalculation.
- Read-only roles no longer see event-creation entry points and cannot remain on the creation route.
- Dashboard and readiness visuals use semantic status so hard blockers cannot appear green.
- Audit history supports server-side search and pagination.
- Dashboard, Events and Media provide dedicated mobile layouts without page-wide horizontal scrolling.
- Dialogs trap focus, close with Escape, restore focus and lock background scrolling.

## Engineering Improvements

- Event owners are validated as members of the active workspace on create and update.
- Email-domain access policies require at least one approved domain before they satisfy readiness.
- Every persisted readiness change reconciles stale recommendations and opens only current evidence gaps.
- Concurrent access-token failures share one refresh request; `/auth/me` and logout can recover an expired access token.
- Dashboard aggregation moved into a service and media domain logic moved out of the controller.
- Launch Control forms and types were split from orchestration, with shared permission and readiness UI helpers.
- OpenAPI now documents content updates, media detachment, audit query parameters and key response schemas.

## Regression Evidence

- API e2e coverage includes refresh rotation, cross-tenant owner rejection, recommendation reconciliation and media detachment.
- Browser coverage includes the complete Archived lifecycle, analyst routing and 390 px overflow checks.
