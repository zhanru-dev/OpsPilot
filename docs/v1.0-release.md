## Defects Found During Verification

1. New Draft events originally presented `Mark ready` without a UI path to Configuring. The UI now follows the backend state machine with `Start configuring` followed by `Mark ready`.
2. The API moved from port 4000 to the configurable port 4100 to avoid common local service conflicts.
3. Next.js did not read the monorepo root environment file for its browser bundle and used an old local API fallback. The formal fallback now matches 4100 while remaining deployment-overridable.
4. Two small status badges failed WCAG AA contrast at 3.83:1 and 4.36:1. Shared amber and muted tokens were darkened and axe verification passed.
5. The selected Nest Swagger release line introduced a newly disclosed YAML parser vulnerability. The project now uses an explicit OpenAPI 3.1 contract with a smaller Swagger UI dependency and passes production audit.

## Honest v1.0 Boundaries

- Media processing is a deterministic workflow adapter; there is no user upload or transcoding claim.
- Demo identities and business data are fictional seed records.
- The application is verified locally but not yet deployed or observed under real traffic.
- Recommendations are deterministic rules, not an LLM.
- Real attendee registration, billing, webhooks and external integrations are out of scope.

## Next Release Gate

v1.1 starts only after v1.0 is presented and understood. Its principal goal is one real media pipeline: object storage, signed upload, metadata extraction, FFmpeg worker, retries, failure visibility and idempotent delivery.
