# OpsPilot v1.1 Release Record

Release date: 14 August 2026

Version: `1.1.0`

Status: locally complete and verified

## Release Goal

v1.1 turns the v1.0 operational decision loop into a flagship full-stack system by adding one bounded real media pipeline and one reliable asynchronous integration. It does not claim to be a livestream delivery platform.

## Delivered

### Private media pipeline

- Short-lived, size- and MIME-bound presigned browser uploads to private S3-compatible storage.
- MP4, MOV, MP3, WAV and M4A profiles capped at 100 MB and five minutes.
- Server-side object validation followed by a persisted BullMQ processing job.
- ffprobe validation of actual duration and codec.
- FFmpeg H.264/AAC video preview and JPEG thumbnail, or MP3 audio preview.
- Persisted progress, attempts, error codes, retries, variants, audit records and domain events.
- Five-minute signed derivative playback URLs.
- Hourly cleanup of expired upload intents and 24-hour non-seeded demo media.

### Reliable integration workflow

- Transactional domain-event outbox for `event.ready` and `event.started`.
- Workspace subscriptions and one safe local demo receiver.
- HMAC-SHA256 payload signatures, replay-window checks, trace IDs and idempotency keys.
- Bounded exponential retry with persisted response status, duration and error evidence.
- Unique domain-event/endpoint deliveries for duplicate suppression.
- Integration Centre endpoint inventory, status counts, attempts and manager-authorised manual retry.

### Operations

- PostgreSQL, Redis and MinIO in Docker Compose.
- Independent API, web and background worker processes.
- Dependency readiness for PostgreSQL, object storage and queues.
- Authenticated queue depth and persisted outbox/webhook failure metrics.
- Structured worker logs and a media/webhook recovery runbook.

## Known Boundaries

- MinIO is a local-development S3-compatible service; production should use a supported managed provider.
- The receiver URL is server-generated. Arbitrary customer webhook URLs require SSRF controls and secret rotation.
- Processing creates one preview profile, not HLS/DASH ladders, DRM or live ingest.
- Codec validation is not malware scanning. Real customer uploads require an additional scanning boundary.
- Queue metrics are JSON operational counters, not yet exported to a hosted metrics backend.
- The seeded retry adapter remains only for the original deterministic v1 media fixture.
